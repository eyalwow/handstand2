## היקף הבדיקות

- רוחבים: 320×640, 360×640, 390×720, 430×780, 1440×900; נוסף 780×390. טקסט 100% ו־200% באמצעות גודל גופן בסיס, לא zoom של מערכת הפעלה.
- 24 פתיחות סינון, 48 מעברי תרגילים, 12 מחזורי Back/Forward/כניסה חדשה, 20 מעברי סרגל דסקטופ, 24 הפעלות שלד ו־96 בדיקות גאומטריית נגן; ללא דילוגים בבדיקת הקבלה המלאה.
- בדיקות קיימות לפני התיקון: 147/147. אחרי התיקון: 151/151, כולל ארבע בדיקות חדשות. בדיקות אלה מכסות גם חוזי אחסון, פרטיות, אימונים ו־Coach; אינן מחליפות בדיקות דפדפן.
- סבב הדפדפן הקיים: 60 צירופי פריסה/axe וחמישה מסלולי שימוש, כולל חיפוש/סינון, Front Lever, חלונית תרגיל ו־Escape, סט/מנוחה/ביטול/רענון/סיום וסיכום. אין overflow או הפרות axe חמורות/קריטיות בצירופים שנבדקו.
- בדיקת מצבים משלימה: MP4 פגום, גוף לא מזוהה, ביטול, מסלול זמן ללא ציון/שמירה, שמירת רשומת ציון ללא שינוי לאחר רענון, סיכום היסטוריה ו־Escape, וכשל טעינת MediaPipe. נוסף סבב axe לתוצאות ולנגן ב־20 צירופי חלון/טקסט; אפס הפרות. [תוצאות המצבים](pr50-regressions/states.json) · [60 בדיקות הנגישות הכלליות](pr50-regressions/accessibility.json).
- `mobile`: התקנה נקייה עם ignore-scripts, אריזה מקומית של 44 מודולים עם נכסי MediaPipe מקומיים; 5/5 בדיקות אריזה. זו אינה הוכחה לניתוח במכשיר פיזי.
- ניתוח אמיתי של Pexels 8859854 אנכי, 1080×1920, ושל דוגמת UCF101 HandstandPushups אופקית. התוצאות באותו קלט: 71/100 ו־14.2 שנ׳ לאנכי, 58/100 ו־2.2 שנ׳ לאופקי; במסלול תנאי צילום לא ודאיים אין ציון. ב־#49 וב־#50 המקורי אותו קובץ אנכי הניב גם 71 ו־14.2. ה־70 בדוח המשתמש אינו משוחזר בקובץ ההורדה הזה; אין כאן טענה למדידת אמת או לכיול.
- CDN לא היה נגיש ישירות בדפדפן המעבדה. שכבת הבדיקה מגישה את חבילת MediaPipe המקורית והמודל המקורי מהמטמון המקומי, באותן כתובות שהמוצר מבקש. ההסקה עצמה אמיתית. זה אינו מבחן חיבור CDN ב־Preview.
- הסכמה לתנאי הצילום היא קלט בדיקה בלבד; לא אישור אובייקטיבי לזווית, למסגור או להיעדר תמיכה. לא נשמרו סרטונים במאגר ולא בוצעו בקשות POST בבדיקות המקומיות.

## שחזור הבדיקות

```sh
node --test tests/*.test.*
# כל קובץ JS שהשתנה נבדק גם עם node --check
cd mobile
npm ci --ignore-scripts --no-fund --no-audit --cache /tmp/movalyt-npm-cache
npm run build
npm test
cd ..
node scripts/verify-fitness-ui.cjs --axe /path/to/axe.min.js --out /tmp/movalyt-a11y
node scripts/verify-pr50-regressions.cjs --out /tmp/movalyt-regressions \
  --video /path/to/public-portrait.mp4 --landscape-video /path/to/public-landscape.mp4 \
  --vision /path/to/@mediapipe/tasks-vision --model /path/to/pose_landmarker_lite.task
```

ההרצה דורשת Playwright ו־Chromium קיימים; אין התקנת תלות חדשה באפליקציה. אפשר לספק `--chromium`, `--port`, `--source`. ללא `--video` בדיקות הנגן מסומנות כ־skipped במפורש. `--vision`/`--model` אופציונליים כאשר ה־CDN זמין. פלט ברירת המחדל הוא `.artifacts/` שאינו נכנס ל־Git. השתמשו בקליפים מורשים שאינם פרטיים; אין לצרף סרטוני משתמשים או אבחונים מזהים ל־PR.

## גבולות השינוי ומגבלות

נשמרו המיתוג והשדרוג העיצובי של #50. שונו פריסה, פוקוס, ניווט והצגת מונה בלבד. מנוע הניתוח, ספים, נוסחאות, ציונים, מודל, סכמות ומפתחות נתוני המשתמש, מנוע האימון ו־API המאמן לא שונו. מצב browser history החדש הוא מצב ניווט בלבד, ללא כתיבה ל־localStorage. לא שולב #48, לא בוצע Merge ולא שונו Production או הגדרות Vercel.

סביבה: Linux, Node 24.19.0, Chromium 154.0.8037.57. WebKit לא עולה בגלל ספריות מערכת חסרות; Safari, VoiceOver ומכשירי iPhone/Android פיזיים לא נבדקו. מבחן מגע ב־Chromium ומבחן ללא פוקוס אוטומטי אינם מבחן Safari. הגדלת נגן נבדקה בתוך האפליקציה; לא נטען שנבדק מסך מלא של מערכת ההפעלה.

ניסיון npm ci ראשון נכשל משום שמטמון ברירת המחדל נמצא מחוץ לתיקיות הכתיבה של הסביבה; התקנה חוזרת עם מטמון זמני מורשה הצליחה, ואחריה האריזה וכל חמש הבדיקות עברו.

בדיקת Vercel וה־CI של קומיט התיקון מתועדת ב־PR. ה־Preview מוגן בכניסת Vercel; אין לפתוח אותו באמצעות שינוי הרשאות. כשל פרויקט Vercel הנפרד `handstand-coach-demo` קיים גם בבסיס ונוגע לתיקיית root שאינה קיימת; אין לתקן הגדרות פריסה במסגרת זו.
