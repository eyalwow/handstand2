# MOVALYT — סגירת Back ושיפורי אימון ממוקדים ב־PR #50

18 בנובמבר 2026. בסיס: `7cfe369b574f14d7630aebcc326b5d3b65845c56`, ענף `feat/movalyt-fitness-polish`, על בסיס #49. תיקון הניווט נמצא בקומיט `ef3e068`; שיפורי ה־UX נוספו רק אחרי שבדיקת שלב א׳ עברה. לא שולב #48 ולא בוצעו Merge או שינויי Production/Vercel.

מקור דרישות ה־QA/UX הוא הסיכום המלא שהמשתמש הדביק בשיחה: 7/8 תיקונים אושרו ב־Work ובאג Back נשאר. דוחות Library המקוריים לא נפתחו; אין כאן טענה לקריאתם. הבדיקות והצילומים להלן עצמאיים. דוח 15 בנובמבר הוא תיעוד היסטורי, ואינו הוכחה שה־Back בין מסמכים עבד ב־7cfe369.

## שלב א׳ — תקלה, תיקון ואימות

### הבעיה ששוחזרה לפני השינוי

ב־50 תרחישים מקומיים בקומיט הבסיס: קטלוג → היסטוריה → Back שמר גלילה ב־20/20; קטלוג → אימונים → Back איפס אותה ב־20/20; רענון איפס אותה ב־10/10. נבדקו 320, 360, 390, 430 ו־1440px וטקסט 100%/200%. [נתוני הבסיס](pr50-final/before-navigation.json).

באימות נפרד, חיפוש `a` עם סינון `all`, מיון `name` וגלילה 350 חזר מאימונים עם חיפוש ריק וגלילה 0, אף שהסינון והמיון נשארו. [ראיה](pr50-final/before-search.json). בקוד הבסיס שדה החיפוש לא נשמר כלל; שימור ה־selects היה תלוי בשחזור טפסים של הדפדפן ואינו חוזה ניהול מצב אמין.

### שורש הבעיה ומה השתנה

- `updateSelection()` הפעילה route באתחול, ואחריה הופעלה route שוב. השחזור השני לאותה רשומה בחר 0 והגדיל revision, שביטל את היעד התקין מהקריאה הראשונה. כעת בחירת התרגיל הראשונית מכינה את התצוגה, וניתוב ראשוני מתבצע אחרי הקמת הספרייה.
- בקר הגלילה עמיד לקריאות חוזרות: שחזור ממתין לאותה רשומה מחזיר אותה בקשה ואינו מחליף יעד; רינדור נוסף אחרי השחזור משמר מיקום חי. revision משתנה במעבר לרשומה אחרת, ו־callbacks מיושנים עדיין נפסלים.
- מיקומים ומצב קטלוג שייכים לרשומת browser history, לא לשם המסך. נשמרים חיפוש, סינון, מיון ומצב הפאנל; הם משוחזרים לפני בניית רשימת התוצאות והגלילה.
- snapshots נכתבים ל־history.state תוך שימור שדות זרים, ומגובים במטמון ניווט זמני של הטאב. הוא שורד החלפת מסמך ורענון, גם כאשר גיבוי pagehide מאוחר מדי, ומאפשר חזרה לרשומות פנימיות ישנות שאיבדו את ה־Map בזיכרון.
- המטמון משתמש במפתח sessionStorage נפרד `movalyt-navigation-v1`, מוגבל ל־64 רשומות אחרונות, וכולל רק מזהה/כתובת, גלילה ומצב קטלוג. זו תוספת metadata של ניווט, ללא שינוי סכמות או מפתחות נתוני המשתמש הקיימים. אין בו וידאו, ציונים, תנוחות או נתוני אימון. כתיבות history בזמן גלילה מאוחדות כדי להימנע מכתיבה בכל פריים; חסימת אחסון מטופלת ללא איפוס נתוני משתמש.
- בכניסה חדשה לקטלוג נוצרת רשומה חדשה שמתחילה ב־0; Back/Forward חוזרים למיקום של הרשומה הקודמת. מסכי האימון נשארו מסמכים נפרדים עם השחזור הטבעי של הדפדפן.

### בדיקות שלב א׳ לפני התחלת UX

עברו 220 תרחישי דפדפן, ובהם 60 חזרות עם BFCache מאומת באמצעות pageshow.persisted. הבדיקה בוצעה גם כאשר BFCache כבוי, ונבדק שהמסמך אכן נוצר מחדש בחזרה מאימונים. כולל שלושה מחזורי Back/Forward, רענון כפול, רענון האימונים לפני Back, ושני ביקורים בקטלוג עם חיפושים ומיקומים עצמאיים, לרבות חזרה לרשומות הישנות. בכל זוג עם פריסה זהה נדרשת סטייה עד פיקסל, יחד עם התאמה מלאה של מצב הקטלוג.

בדיקות היחידה מכסות גם שתי הפעלות באתחול לפני RAF, רינדור חוזר לאחר שחזור, ביטול בקשה מיושנת, אובדן המסמך ללא pagehide, metadata פגום ואחסון חסום. אין החלפה של בדיקות הדפדפן בבדיקות אלה.

## שחזור

```sh
node --test tests/*.test.*
node scripts/verify-navigation-history.cjs --out /tmp/movalyt-navigation
node scripts/verify-training-ux.cjs --video /path/to/authorized-public.mp4 --out /tmp/movalyt-training
node scripts/verify-fitness-ui.cjs --axe /path/to/axe.min.js --out /tmp/movalyt-a11y
node scripts/verify-pr50-regressions.cjs --out /tmp/movalyt-regressions \
  --video /path/to/public-portrait.mp4 --landscape-video /path/to/public-landscape.mp4 \
  --vision /path/to/@mediapipe/tasks-vision --model /path/to/pose_landmarker_lite.task
cd mobile
npm ci --ignore-scripts --no-fund --no-audit --cache /tmp/movalyt-npm-cache
npm run build
npm test
```

הסקריפטים דורשים Playwright ו־Chromium קיימים. --source מאפשר לבדוק עותק אחר, --out מבודד ראיות ו־--port מונע התנגשות. בלי --video בדיקות הווידאו מסומנות skipped; בהרצה המתועדת סופקו קליפים אמיתיים. אין התקנת תלות אפליקציה חדשה.

## מגבלות ופריסה

Linux / Chromium 154. WebKit נבדק להפעלה אך לא עלה בגלל ספריות GTK4/Graphene/Harfbuzz/Manette/Hyphen/GLES חסרות. Safari, VoiceOver, מכשירי iPhone/Android פיזיים, התקנה/חתימה, מצלמה ו־background/resume לא אומתו. גודל חלון אינו סיבוב מכשיר פיזי. בניית Android, אם עברה ב־CI, אינה בדיקת מכשיר. תנאי ה־CI הקיים מדלג על בניית iOS ב־PR זה.

ה־Preview הראשי ותוצאות ה־CI של קומיט הסיום מפורטים ב־PR #50. ה־Preview עשוי לדרוש כניסת Vercel; בדיקות הדפדפן לעיל מקומיות. הגדרות הגנה לא שונו. פרויקט Vercel הנפרד handstand-coach-demo נכשל גם בבסיס בגלל root מוגדר שאינו קיים; אין שינוי בו במסגרת התיקון.
