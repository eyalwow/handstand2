## Corrected behavior

- **Availability:** one registry-derived query drives family cards, per-variant labels, onboarding badges and the supported/experimental filter. Handstand displays `ניתוח פעיל`. Front Lever displays `ניתוח ניסיוני · 5 וריאציות · ללא ציון`. Unimplemented items display `ניתוח לא זמין`. The family itself remains non-dispatchable; only the five existing unassisted experimental variants can open its analysis path. Super Advanced Tuck and every band-assisted mode stay unavailable. No score or new analyzer is enabled.
- **Desktop:** catalog, variation and guide screens expand from the inherited 480px shell to a maximum of 1120px; other app screens keep the existing shell. The grid uses a 260px minimum at desktop/tablet sizes rather than squeezing three columns into the phone shell. The six desktop cards have three useful columns; the exact measured widths are in the browser evidence. Variation artwork slots use a larger 1.6 aspect ratio, with no new image assets.
- **Mobile:** the variation screen uses its bottom space for a fixed Continue action and current-selection label. The navigation bar is temporarily hidden on this screen; the visible Back link returns to the library. The action accounts for the iPhone safe area, and a border-box ResizeObserver reserves the actual action height plus spacing so the last card can scroll clear. The border-box choice matters: safe-area padding can change even when text height stays constant.
- **Readability:** library step/count captions are 14px rather than 10px. Variation cards show their own variant name rather than repeating the family name and common measurement type. One match reads `תרגיל אחד`. The experimental history heading is Hebrew.
- **Names:** central cards, variation headings, search, filming definitions, history options, report names, playback caption and image alternative text use `פרונט לבר`, `בק לבר`, `פלאנץ׳`, `טאק`, `אדוונס טאק`, `סופר אדוונס טאק`, `סטראדל` and `מלא`. English catalog metadata remains searchable. Variant names also participate in family search. Original training names used as legacy keys stay untouched. All 158 exercise IDs/history IDs/legacy training-name identities are guarded by a pre-QA SHA-256 snapshot. Stored data and keys are not rewritten.

The Front Lever playback name is translated in the presentation finish hook, keeping the underlying Handstand engine file byte-identical. Front Lever report rendering uses the translated catalog names, with no change to inference, criteria or scoring.
