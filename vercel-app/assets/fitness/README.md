# Original fitness artwork — first screened group

Created 2026-10-27 with OpenAI image generation for this Handstand Lab project.
Original generated content; no downloaded, traced or copied third-party application artwork.
The existing Workout Guide / Everkinetic files and their CC BY-SA notices are separate and unchanged.

## Art direction and files
Neutral grayscale athlete, charcoal background, restrained muted green emphasis.
Each movement has its own files. No movement is reused for an unrelated variant.
Detail/workout JPEGs: 512×384 (4:3). Card JPEGs: 320×240 (4:3), softly downsampled
to reduce small anatomical texture; this is not a separately redrawn anatomy model.
The complete released first group (16 files) is under 190 KB. Lazy loading applies
to cards/details; workout images load eagerly. Static holds use one image.
Dynamic movements use separate first and second positions with textual labels.
The original generation sheet was exported into individual panels, normalized and encoded
for mobile delivery. The intermediate sheet is not a shipped asset.

## Visual and technical screening
This is a visual review against published technique guidance, not professional anatomy
certification, an EMG/activation map, or a physical demonstration by a qualified coach.
Green patches are illustrative emphasis; they should not be read as a precise muscle map.
Keep independent coach review as a release gate before any production rollout.

- Pull-up: bar contact, straight-arm hang and visibly higher bent-arm position, chin over bar;
  no kipping depicted. Front view does not show all back muscles.
- Push-up: straight trunk/hip/leg alignment, hands supporting the body, distinct straight/bent elbows.
- Squat: standing versus bent hip/knee position, feet remain grounded. A side illustration cannot
  establish frontal knee alignment for an individual.
- Parallel-bar dip: actual parallel bars, supported hands, straight-arm versus lowered support.
  Bent knees in the lower frame are a leg position option, not the source of upward movement.
- L-sit: one static hold on parallettes, straight supporting arms and legs projected forward;
  explicitly not mapped to the catalogue's bent-knee L-sit.
- Hollow hold: one static supine shape, raised shoulders/legs and low-back/pelvic support;
  viewed as an illustrative shape, not proof of an individual's spinal position.
- WITHHELD: the generated wall-handstand candidate. Chest/back-to-wall orientation is not
  sufficiently clear. No new artwork is mapped to that movement until corrected and reviewed.
