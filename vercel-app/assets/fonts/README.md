# Rubik fonts

Hebrew and Latin weights 400, 600 and 800, normal style, WOFF2.
Source: `@fontsource/rubik@5.2.8`, downloaded using npm's verified package path.
Project: https://fontsource.org/fonts/rubik
License: SIL Open Font License 1.1; complete original text is in `OFL.txt`.

Bundled for reproducible Hebrew typography and to avoid a runtime Google Fonts
request. No proprietary font service or paid font was used.
